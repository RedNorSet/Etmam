Tester 1 — Authentication & Student Dashboard Login system · session management · student overview · notifications
12 Cases
# Use Case Steps to Perform Expected Result ✓ Done Notes / What Happened
Authentication
1.1 Successful Login Critical
  1. Go to /accounts/login/
  2. Enter a valid username and password
  3. Click "Sign In"
 User is redirected to their role's dashboard. No error shown.
1.2 Wrong Password
  1. Go to login page
  2. Enter a valid username but wrong password
  3. Click "Sign In"
 Error message shown. User stays on login page. Failure is counted.
1.3 Account Lockout Security
  1. Enter wrong password 5 times in a row for the same user
  2. Try to login with the correct password
 Account is locked after 5 failures. Even correct password is rejected with a lockout message.
1.4 Session Timeout Security
  1. Log in as any user
  2. Leave the browser idle for 15 minutes without any action
  3. Try to navigate to any page
 User is redirected to the login page (session expired after 15 min of inactivity).
1.5 Role-Based Redirect
  1. Log in as a student → note URL
  2. Log out and log in as a supervisor → note URL
  3. Log out and log in as an administrator → note URL
 Student → /dashboard/student/, Supervisor → /dashboard/supervisor/, Admin → /dashboard/admin/
1.6 Access Restriction Security
  1. While logged in as a student, manually navigate to /dashboard/admin/
  2. Also try /dashboard/supervisor/
 Student is redirected away — cannot access admin or supervisor pages.
1.7 Logout
  1. Log in as any user
  2. Click the logout button
  3. Try pressing browser Back button
 User is logged out and redirected to login. Back button does not restore the session.
Student Dashboard
1.8 Dashboard Overview (No Team) Phase 1
  1. Log in as a student who is NOT in any team
  2. View the student dashboard
 Dashboard shows a "no team" state. Analytics charts are hidden. Supervisor list is visible.
1.9 Dashboard Overview (With Team) Phase 2
  1. Log in as a student who IS in a team with a project
  2. View the student dashboard
 Milestone Completion chart, Task Completion chart, and Milestone Timeline are all visible and correct.
1.10 Milestone Completion Chart
  1. Log in as a student with a project that has at least 1 submission
  2. Check the "Milestone Completion" doughnut chart
  3. Count submitted milestones manually and verify
 Chart center shows "X / Y submitted" matching the actual submission count. Percentage is accurate.
1.11 Milestone Timeline — Full Names
  1. Log in as a student with a project
  2. Scroll to the "Milestone Timeline" section
  3. Check if all milestone names are fully visible
 All milestone names shown in full — no "Project Prop..." truncation. Text wraps cleanly.
1.12 Notification Bell
  1. Log in as a student with unread notifications
  2. Check the notification count badge
  3. Click a notification to mark it read
  4. Refresh and check the count again
 Badge shows correct unread count. After clicking, the notification is marked read and count decreases.

Tester 2 — Team Formation & Management Creating teams · invitations · leader management · supervision requests
12 Cases
# Use Case Steps to Perform Expected Result ✓ Done Notes / What Happened
Team Creation
2.1 Create Team (Student) Phase 1 Critical
  1. Log in as a student not in any team
  2. Go to the "Team" section on the student dashboard
  3. Create a new team with a name
 Team is created. Student becomes the team leader. Team appears in their dashboard.
2.2 Invite Team Member Phase 1
  1. As team leader, go to the team section
  2. Search for another student (same department)
  3. Send an invitation
 Invitation is sent. The invited student receives a notification. Invite shows as "pending".
2.3 Accept Team Invitation Phase 1
  1. Log in as the invited student
  2. Go to the pending invitation on the dashboard
  3. Accept the invite
 Student joins the team as a member. Both students can see each other in the team section.
2.4 Decline Team Invitation
  1. As a student with a pending invite, decline it
 Student does not join the team. Team leader can still invite others.
2.5 Cross-Department Invite Block Security
  1. As team leader, try to invite a student from a different department
 Invitation is blocked with an error about department mismatch. Student is not invited.
Admin Team Management
2.6 Admin Creates a Team
  1. Log in as administrator
  2. Go to Teams & Projects panel
  3. Click "Create New Team" and fill in name and members
 Team is created with assigned members. A leader is set. Team appears in the table.
2.7 Admin Adds Member to Existing Team
  1. As admin, expand a team in the Teams panel
  2. Search for a student and add them
 Student is added to the team. Appears in the team's member list immediately.
2.8 Admin Changes Team Leader
  1. As admin, expand a team with multiple members
  2. Use "Change Leader" to assign a different member as leader
 The selected member becomes the new leader. Previous leader becomes a regular member.
Supervision Requests
2.9 Student Sends Supervision Request Phase 1
  1. Log in as a student (team leader)
  2. Browse the available supervisors on the dashboard
  3. Send a supervision request to one of them
 Request is sent. Supervisor receives a notification. Status shows "pending" for the student.
2.10 Supervisor Accepts Request Phase 1 Critical
  1. Log in as the supervisor who received the request
  2. Go to the pending requests section
  3. Accept the request
 Supervisor is assigned to the team's project. Student receives a notification. Project shows supervisor name.
2.11 Supervisor Declines Request
  1. As the supervisor, go to pending requests
  2. Decline a supervision request
 Request is declined. Student receives a notification. Student can still send requests to other supervisors.
2.12 Supervisor at Capacity Block
  1. As admin, find a supervisor who has reached their team limit
  2. Try to manually assign another project to them
 Error message saying the supervisor has reached their limit. Assignment is blocked.

Tester 3 — Milestones & Submissions Submitting files · resubmissions · late submissions · task tracking · admin milestone setup
12 Cases
# Use Case Steps to Perform Expected Result ✓ Done Notes / What Happened
Admin: Milestone Setup
3.1 Admin Creates Milestone Critical
  1. Log in as admin, go to the Milestones panel
  2. Create a new milestone with title, start date, due date, and weight
  3. Optionally upload a guide file
 Milestone is created. All active teams receive a notification. Milestone appears in student dashboards.
3.2 Admin Edits Milestone Due Date
  1. As admin, find an existing milestone in the Milestones panel
  2. Edit it and change the due date
  3. Save changes
 Due date is updated. Teams and supervisors receive a "due date changed" notification.
3.3 Admin Sets Milestone Weights
  1. As admin, go to the Grades panel
  2. Adjust weights for each milestone so they total exactly 100%
  3. Save weights
 Weights saved successfully. Success message confirms total is 100%. A warning appears if they don't sum to 100.
3.4 Admin Deletes Milestone
  1. As admin, delete an existing milestone from the Milestones panel
 Milestone is removed. It no longer appears in student dashboards or submission panels.
Student: Submissions
3.5 Submit Milestone (First Time) Phase 2 Critical
  1. Log in as a student (team leader) with an active project
  2. Go to the Milestones section
  3. Upload 1–3 allowed files (PDF/DOC/PPT/ZIP/image) for an open milestone
  4. Click Submit
 Submission is saved as v1. Supervisor and reviewers receive a notification. Milestone shows as submitted.
3.6 Resubmit (v2) Phase 2
  1. Submit a milestone again (after the first submission)
  2. Upload a different file
 New submission is created as v2. Previous submission is still in the database (is_latest=False). Version counter increments.
3.7 Submission Limit Enforced
  1. Keep resubmitting until you reach the team's max resubmission limit
  2. Try to submit one more time
 System blocks the submission with "You have used all X submission(s) allowed" error.
3.8 Blocked File Type Upload
  1. Try to upload a file with a disallowed extension (e.g. .exe, .mp4)
 Upload is rejected with an error listing allowed file types. No file is saved.
3.9 Non-Leader Cannot Submit Security
  1. Log in as a student who is a team MEMBER (not leader)
  2. Try to submit a milestone
 Submission is blocked with "Only the team leader can submit" error.
Task Tracking
3.10 Create a Task
  1. Log in as a student (team leader)
  2. Go to a milestone in the Milestones section
  3. Create a task, assign it to a team member, set a due date
 Task appears in the milestone. Assigned member receives a notification.
3.11 Update Task Status
  1. Log in as the student a task is assigned to
  2. Change the task status from "To Do" → "In Progress" → "Done"
 Status updates correctly. Task completion count in the dashboard chart updates.
3.12 Admin Manages Submission
  1. As admin, go to the Submissions panel
  2. Find a submission and change its status (Pending → Approved)
  3. Delete a submission
 Status is updated. Deleted submission is removed from the list.

Tester 4 — Grading System Supervisor grading · reviewer grading · admin grade panel · archived project exclusion · analytics charts
12 Cases
# Use Case Steps to Perform Expected Result ✓ Done Notes / What Happened
Supervisor Grading
4.1 Supervisor Grades a Submission Critical
  1. Log in as a supervisor with at least one team's submission
  2. Go to the Submissions section on the supervisor dashboard
  3. Enter a grade (0–100) for a submission and save
 Grade is saved. Students on that team receive a notification. Grade appears in the grading table.
4.2 Supervisor Grades Split Milestone (Report + Presentation)
  1. Find a milestone that has a Report + Presentation split
  2. As supervisor, grade both components separately
 Both component grades are saved. The weighted overall grade is calculated correctly based on split percentages.
4.3 Invalid Grade Rejected
  1. As supervisor, try to enter a grade of 101 or a negative number
  2. Try entering text (e.g. "A+")
 Error message: grade must be between 0 and 100. No invalid grade is saved.
Reviewer Grading
4.4 Reviewer Grades a Submission Critical
  1. Log in as a user with reviewer role assigned to a project
  2. Go to the reviewer grading section for a submission
  3. Enter a reviewer grade and save
 Reviewer grade is saved. The overall submission grade is recalculated averaging supervisor + reviewer grades.
4.5 Reviewer Cannot Grade Non-Assigned Project Security
  1. Log in as a reviewer assigned to Project A
  2. Try to manually access the grade form for Project B (not assigned)
 Access is denied. Reviewer can only grade projects they are assigned to.
Admin Grade Panel
4.6 Admin Saves Grades from Grade Table Critical
  1. Log in as admin and go to the Grades panel
  2. Enter grades for multiple projects and milestones
  3. Click "Save All Grades"
 All entered grades are saved. Success message shows count of saved grades.
4.7 Archived Projects Excluded from Grades
  1. As admin, go to the Grades panel
  2. Check if any project with "completed" status appears in the grading table
 Archived (completed) projects do NOT appear in the grade table. Only active projects are listed.
4.8 Archived Projects Excluded from Milestones Missed
  1. As admin, go to the Submissions panel
  2. Check the "Not Submitted" list for each milestone
 Archived projects do NOT appear in the "not submitted" (missed) lists.
Analytics Charts
4.9 Average Score per Milestone Chart
  1. Log in as admin and go to the Analytics panel
  2. Find the "Average Score per Milestone" bar chart
  3. Manually calculate the average for one milestone using the grade table and compare
 Chart averages match the manual calculation. Zero grades are correctly included in the average.
4.10 Active vs Archived Teams Chart
  1. In the Analytics panel, find the "Active vs Archived Teams" doughnut
  2. Count active and archived teams manually and compare
 Chart shows only 2 segments (Active, Archived). No "Dissolved" segment. Center shows total team count. Numbers match reality.
4.11 Auto Zero for Missed Overdue Milestone
  1. Find a milestone whose due date has passed
  2. Find an active project that did NOT submit for that milestone
  3. As admin, load the dashboard and check the grade table for that project/milestone
 A grade of 0 is automatically entered for the missed submission in the grade table.
4.12 Student Milestone Completion Chart Accuracy
  1. As a student with 2 out of 4 milestones submitted
  2. Check the "Milestone Completion" chart on the student dashboard
 Chart shows 50% with center label "2 / 4 submitted". Doughnut is half green, half grey.

12 Cases

Phase Management
5.1 Phase 1 → Phase 2 Switch Critical
  1. Log in as admin and go to the System panel
  2. Run the Phase 2 preflight check — review any warnings
  3. Confirm and execute the Phase 2 switch
  4. Check that auto-teams were created and supervisors assigned
 Phase switches to 2. Auto-teams created for teamless students. Supervisors and reviewers auto-assigned. Success message with counts. Students can now submit.
5.2 Revert to Phase 1
  1. As admin (while in Phase 2), revert back to Phase 1 via the System panel
 Auto-assigned supervisors are removed. Auto-created teams are dissolved. System returns to Phase 1. Declined supervision requests are re-opened.
5.3 Students Cannot Submit in Phase 1 Security
  1. While the system is in Phase 1, log in as a student and try to submit a milestone
 Submission is blocked with message "Submissions are not open yet. System is still in Phase 1."
Archive Management
5.4 View Archive
  1. As admin, go to the Archive panel
  2. Check that only completed projects appear
  3. View project details, members, and final files
 Archive shows only completed projects. Each entry has project title, team, supervisor, and members.
5.5 Toggle Archive Visibility
  1. As admin, in the Archive panel, hide a project from the public archive
  2. Log in as a student and check the archive page
  3. As admin, unhide it and check again
 Hidden project does not appear in student/supervisor archive views. Unhiding restores it.
5.6 Add Manual Archive Project
  1. As admin, in the Archive panel, add a historical project manually
  2. Fill in project name, team name, supervisor, and member names
 Project appears in the archive immediately. Members are listed as inactive users.
Meetings
5.7 Schedule a Meeting Critical
  1. Log in as a supervisor
  2. Go to the Meetings section and schedule a meeting for one of your teams
  3. Add participants and set date/time
 Meeting is created. All participants receive an invitation notification. Meeting appears in upcoming meetings.
5.8 Student Accepts/Declines Meeting
  1. Log in as a student who received a meeting invitation
  2. Accept the meeting invitation
  3. Log in as another student and decline their invitation
 Responses are recorded. Supervisor can see who accepted and who declined.
5.9 Reschedule a Meeting
  1. As a supervisor, find an upcoming meeting and propose a reschedule
  2. Set a new date/time and submit the proposal
  3. As the meeting organizer, accept the reschedule
 Meeting is updated to the new time. Participants receive a notification about the change.
User Management & Logs
5.10 Admin Manages User Accounts
  1. As admin, go to the Users panel
  2. Add a new supervisor user
  3. Edit an existing student's department
  4. Deactivate a student account
 All changes take effect. Deactivated student is logged out immediately on next request.
5.11 Verify Logs: Login Events
  1. Check the server/Render logs (or run the server locally and check the terminal)
  2. Log in as a student, then log out
  3. Try a wrong password once
  4. Check the log output
 Logs show: [INFO] gpms.auth: LOGIN user=... role=... ip=..., [INFO] gpms.auth: LOGOUT user=..., [WARNING] gpms.auth: LOGIN_FAILED username=...
5.12 Verify Logs: Key Actions
  1. As a student, submit a milestone and check logs
  2. As admin, assign a supervisor and save grades — check logs
  3. Switch to Phase 2 — check logs
 Logs show: SUBMIT user=..., SUPERVISOR_ASSIGNED admin=..., GRADES_SAVED admin=..., PHASE2_SWITCH admin=... — all with correct details.
